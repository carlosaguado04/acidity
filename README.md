# Acidity

Studio site for [acidity.lol](https://acidity.lol).

## Run locally

```bash
bun install
bun run dev
```

Open http://localhost:5173

## Scripts

- bun run dev
- bun run build
- bun run preview

## Stack

- Vite + TypeScript
- GSAP jelly hero mascot (public/mascot.png)
- Lenis + GSAP ScrollTrigger
- Syne display + system UI fonts
- Dark/light theme
- Mascot logo at public/mascot.png

## Motion and accessibility

Effects respect prefers-reduced-motion: reduced motion skips Lenis/GSAP, freezes the mascot to a still pose, and shows content without reveals.

## Brand notes

ink #0C0D10, raised #16181D, edge #23262C, paper #F4F4F2, acid #D8FF47 (sparse).
