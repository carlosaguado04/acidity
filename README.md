# Acidity

Studio site for [acidity.lol](https://acidity.lol).

Two pages: `/` and `/work`.

## Run locally

```bash
bun install
bun run dev
```

Open http://localhost:5173

## Scripts

- bun run dev
- bun run build
- bun run preview

## Work crops

Drop real PNGs (or WebP) into:

- `public/apps/mise-crop.png`
- `public/apps/orza-crop.png`
- `public/apps/hilo-crop.png`

Until those files exist, the slides stay type-only. No placeholder chrome.

## Stack

Vite + TypeScript. Satoshi. Anurati is not used — the face has no lowercase, and the wordmark is `Acidity`.

## Brand

ink `#0C0D10`, paper `#F4F4F2`, acid `#D8FF47`.
