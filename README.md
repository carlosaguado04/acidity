# Acidity

Studio site for [acidity.lol](https://acidity.lol).

Home is the letter under a large Anurati wordmark. Work is a frosted glass shelf from the right (`/work`).

## Run locally

```bash
bun install
bun run dev
```

Open http://localhost:5173

## Brand

ink `#0C0D10`, paper `#F4F4F2`.
Accent is neon magenta `#FF3D9A` → cyan `#2EF0EA`.
Anurati on the wordmark only. Satoshi everywhere else.
