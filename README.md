# Acidity

Studio site for [acidity.lol](https://acidity.lol).

Home is the letter. Work is a frosted glass shelf that slides in from the right (`/work`).

## Run locally

```bash
bun install
bun run dev
```

Open http://localhost:5173

## Scripts

- bun run dev
- bun run build
- bun run preview

## Brand

ink `#0C0D10`, paper `#F4F4F2`, acid `#D8FF47`.
Anurati on the wordmark only. Satoshi everywhere else.
