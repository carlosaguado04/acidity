# Acidity

Studio site for [acidity.lol](https://acidity.lol).

Home is the letter. Apps and Work are frosted shelves from the right (`/apps`, `/work`).

## Run locally

```bash
bun install
bun run dev
```

Open http://localhost:5173

## Brand

ink `#0C0D10`, paper `#F4F4F2`, Mexican pink `#E4007C`.
Anurati on the wordmark only. Satoshi everywhere else.
